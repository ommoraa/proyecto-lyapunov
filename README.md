# 📊 Proyecto IRAG Stability Analyzer

Este proyecto implementa un sistema completo de análisis epidemiológico para IRAG (Infecciones Respiratorias Agudas Graves), incluyendo:

- Limpieza y estructuración de datos con Python  
- Pipeline reproducible con DVC  
- Modelo predictivo basado en estabilidad tipo Lyapunov  
- App interactiva construida con Streamlit  
- Seguimiento de experimentos con MLflow
